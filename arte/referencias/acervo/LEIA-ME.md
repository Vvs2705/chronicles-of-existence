# Chronicles of Existence — acervo produzido

Este pacote contém todas as 235 imagens PNG encontradas no acervo desta conversa no momento do empacotamento, sem redução de resolução.

## Como consultar
1. Extraia o arquivo ZIP inteiro.
2. Abra INDEX.html no navegador para consultar as imagens.
3. Use INVENTARIO.csv para conferir nomes originais, tamanhos e SHA-256.
4. Consulte a bíblia de prompts em documentos/ para as 341 fichas de produção.

## Estado da produção
Este é o acervo produzido até esta versão, NÃO a conclusão de todas as 341 fichas e seus desdobramentos. Uma ficha pode exigir várias imagens de vistas, peças, expressões e variantes. Uma imagem gerada não equivale a uma ficha finalizada ou aprovada.

As imagens mais recentes usam uma vista por arquivo. Estudos antigos que continham pranchas ou foram substituídos foram preservados em estudos_historicos; não devem ser usados como referências finais sem revisão. Os nomes originais de arquivos antigos sem identificação consolidada foram preservados.

Os corpos de referência vestem macacão marfim opaco. Roupas e acessórios de produção são separados. Todas as artes são propostas para avaliação e referência; não são modelos 3D prontos.
