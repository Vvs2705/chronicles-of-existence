# Scripts/Audio
Som do jogo sintetizado em codigo, sem arquivo nem licenca: trilha por momento (`SinteseDaTrilha`, escolhida pela `TrilhaDoMomento`), efeitos (`Sintese`, `SinteseDosEfeitos`), ambiente e sons de lugar da vila (`SinteseDoMundo`).
