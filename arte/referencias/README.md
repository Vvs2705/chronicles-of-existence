# Referências de arte (concepts)

Solte aqui as imagens de referência e concept art do COE. Subpastas por assunto são bem-vindas
(`personagens/`, `auren/`, `bosque/`, `limiar/`, `vfx/`...).

- Fica **fora de `client/Assets`** de propósito: o Unity não importa, e o projeto não fica mais pesado.
- `.png`, `.jpg`, `.jpeg`, `.webp` e `.psd` vão para o Git LFS automaticamente (`.gitattributes` da raiz).
- Nome de arquivo sem espaço nem acento ajuda os scripts: `borin_frente_v2.png` em vez de `Borin frente (2).png`.
- Portão de originalidade (ADR-0002): um concept só vira malha depois do G2 (testes cegos de silhueta e descrição).
